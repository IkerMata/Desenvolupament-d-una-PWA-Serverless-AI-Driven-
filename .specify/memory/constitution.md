# EstateFlow Constitution

## Core Principles

### I. Clarity and Trust
Buying or selling a home is a major life event. The UI MUST prioritize clarity, high-quality visuals, and transparency in data (prices, features, status).

### II. Visual Excellence
Real estate is a visual business. The application MUST use high-quality images (via `generate_image`) and a premium, clean design (Glassmorphism, subtle shadows).

### III. Data Integrity
Property data MUST be accurate. Validation for prices, square footage, and contact information is non-negotiable.

### IV. Test-Driven Development (TDD)
As per the Speckit standard, all business logic (filters, calculations) MUST be tested before implementation.

### V. Responsive Performance
The site MUST be fast and usable on mobile devices, as many users browse properties on the go.

## Quality Standards
- **Code Quality**: Zero linting errors.
- **Testing**: 80% coverage for core logic.
- **Design**: Modern typography (Inter/Outfit), HSL color palettes.
